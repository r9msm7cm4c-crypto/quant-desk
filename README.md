# 量化工作台 · Quant Desk

一个可安装的离线量化研究终端：回测、真实日线、真实行情与分钟预测。
纯前端单页应用，无账号、无服务器、无埋点，数据只保存在你的设备上。

## 安装

- **iPhone / iPad**：用 Safari 打开 <https://r9msm7cm4c-crypto.github.io/quant-desk/>，点「分享」→「添加到主屏幕」。
- **Android**：用 Chrome 打开同一地址，菜单 →「安装应用」。
- **电脑**：Chrome / Edge 打开，地址栏右侧点「安装」。

安装后可全屏、离线启动（首次打开需要联网缓存）。

## 功能

- 回测：6 种策略、A 股整手与费用模型、止损止盈、参数扫描、交易明细、回测记录。
- 研究：一条完整的因子研究流水线 —— 数据质控 → 因子检验 → 组合优化 → 稳健回测 → 执行成本，可用内置示例面板先把流程跑通，再切到自己的真实日线。
- 数据：按代码 / 名称获取东方财富前复权日线（A 股 / ETF / 美股），或导入 CSV；可导出。
- 实时：腾讯公开行情 2 秒快照，A 股 / ETF / 美股搜索与自选。
- 预测：东方财富真实 1 分钟线 + 蒙特卡洛，1/5/15/30/60 分钟上涨概率、预期变动与 80% 区间。
- 全部本地运行：localStorage 持久化，可导出 / 导入备份。

## 研究模块

「研究」页按课程里的六步流程组织，每一步都能单独调整参数、立刻看到结果：

| 步骤 | 做什么 | 关键指标 |
| --- | --- | --- |
| 1 数据质控 | 对数收益、Winsorize、偏度 / 峰度 / 异常值、跳空检查、频率转换 | 年化波动、日胜率、样本区间 |
| 2 因子检验 | 动量 / 短期反转 / 低波动 / EP / BP / 小市值，行业+市值中性化 | IC、IR、t 值、胜率、多空价差、累计 IC |
| 3 组合优化 | 均值方差、风险平价、Black-Litterman 主观观点 | 有效前沿、夏普、HHI、风险贡献 |
| 4 稳健回测 | 训练窗选参、测试窗评估的滚动检验 | 样本外年化、胜率、过拟合折损 |
| 5 执行成本 | Almgren 平方根冲击 + 价差 + 佣金，TWAP / 分片 | 冲击 bp、完成天数、占 ADV、成交率 |

因子口径：`X_EP = EPS / P_t`，`X_BP = BPS / P_t`，标准化用 `z = (x - μ) / σ`，
`IC_t = Corr(X_t, R_{t+1})`（Spearman 秩相关），`IR = IC 均值 / IC 标准差`，`|t| > 2` 视为显著。
真实日线缺少 EPS / BPS 时，估值类因子会标成「缺少数据」并自动从合成权重里剔除，不会用 0 冒充。
