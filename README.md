# 量化工作台 · Quant Desk

一个可安装的离线量化研究终端：回测、真实日线、真实行情与分钟预测。
纯前端单页应用，无账号、无服务器、无埋点，数据只保存在你的设备上。

## 安装

- **iPhone / iPad**：用 Safari 打开 <https://r9msm7cm4c-crypto.github.io/quant-desk/>，点「分享」→「添加到主屏幕」。
- **Android**：用 Chrome 打开同一地址，菜单 →「安装应用」。
- **电脑**：Chrome / Edge 打开，地址栏右侧点「安装」。

安装后可全屏、离线启动（首次打开需要联网缓存）。

## 功能

- 回测：6 种策略、A 股整手与费用模型、止损止盈、参数扫描、交易明细、回测记录。
- 数据：按代码 / 名称获取东方财富前复权日线（A 股 / ETF / 美股），或导入 CSV；可导出。
- 实时：腾讯公开行情 2 秒快照，A 股 / ETF / 美股搜索与自选。
- 预测：东方财富真实 1 分钟线 + 蒙特卡洛，1/5/15/30/60 分钟上涨概率、预期变动与 80% 区间。
- 全部本地运行：localStorage 持久化，可导出 / 导入备份。

## 说明

- 行情、日线来自公开接口，可能延迟、限频或停服；不构成投资建议。
- 实时页只做数据与概率研究，不提供任何交易或下单功能。
- 本项目为静态站点，源代码与构建产物均在仓库中。
