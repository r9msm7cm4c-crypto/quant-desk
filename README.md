# 量化工作台 · Quant Desk

两套端，共用同一个仓库：

| 端 | 位置 | 形态 | 适合 |
| --- | --- | --- | --- |
| **主站 · TSP** | `tsp/` | FastAPI + Polars + React，自托管全功能工作台（策略扫描 / 回测 / 因子 / 监控 / AI 助手 / 开放 API + MCP） | 全市场研究、盘中监控、要跑数据管道 |
| **离线版 · PWA** | 仓库根目录 | 单文件静态页，可安装、可离线，数据只在本机 | 随时打开看行情、做单标的回测与研究流水线 |

主站启动后会把离线版同源挂在 `http://<host>:3018/pwa/`，侧栏底部有「离线版」入口。

---

## 一、启动主站（TSP）

```bash
./union.sh start          # 首次会自动装依赖 + 构建前端，然后启动
```

- 主站：<http://localhost:3018>
- 离线版：<http://localhost:3018/pwa/>
- 日志：`.union.log`，停止：`./union.sh stop`

其它命令：

```bash
./union.sh build          # 只构建前端（并把离线版打进 dist/pwa）
./union.sh dev            # 开发模式：后端 3018 + Vite 3011 热更新
```

环境变量：`PORT`（默认 3018）、`HOST`（默认 0.0.0.0）、`DATA_DIR`（默认 `tsp/data`）。
首次启动后按页面引导完成「设置 → 凭据与能力 → 跑一次盘后管道」；没有数据源凭据时走 TickFlow Free 试用模式，仅能取历史日 K 单股数据。

没有数据源凭据时，可以先灌一份演示数据把流程走通（合成数据，仅供试跑）：

```bash
cd tsp/backend && .venv/bin/python ../scripts/seed_demo_data.py
curl -X POST http://localhost:3018/api/kline/rebuild_enriched
```

> 不想用脚本也可以在 `tsp/` 里按上游方式跑：`./dev.sh`（开发）、`docker compose up -d --build`（容器）。

## 二、安装离线版（PWA）

- **iPhone / iPad**：Safari 打开 <https://r9msm7cm4c-crypto.github.io/quant-desk/>，分享 →「添加到主屏幕」。
- **Android**：Chrome 打开同一地址，菜单 →「安装应用」。
- **电脑**：Chrome / Edge 打开，地址栏右侧点「安装」。

也可以直接用主站自带的 `/pwa/` 地址安装，两者数据各自独立（PWA 存 localStorage）。

## 主站能力（`tsp/`）

- **策略引擎**：25+ 内置策略（趋势 / 量价 / 涨停 / 反转），全 A 股 Polars 毫秒级扫表，支持自定义策略文件、ETF 模式、分钟策略。
- **指标流水线**：68 列指标与信号，盘后自动拉日 K + 重算 enriched Parquet，前复权口径统一。
- **回测**：个股 / 策略组合 / 自由信号组合三种模式，T+1、手续费、滑点、止损、最大持仓天数；净值曲线、夏普、最大回撤、胜率、盈亏比、蒙卡回撤、因子归因。
- **因子平台 + 挖掘**：DSL 自定义因子、检验组合、样本外多因子搜索（显式发布，不上线）。
- **市场环境**：情绪周期 6 阶段、概念 / 行业主线排名。
- **监控中心**：竞价 / 盘中 / 偏移全时段异动，弹窗、语音、飞书推送。
- **AI 助手**：自然语言取数，取数过程逐条可见，确认卡放行生成信号 / 跑回测 / 补数据。
- **开放能力**：65 个契约化端点 + Token 六档权限 + SSE 事件流 + MCP 服务。

上游文档在 `tsp/README.md`、`tsp/操作说明书.md`、`tsp/docs/`。

## 离线版能力（仓库根目录）

- 回测：6 种策略、A 股整手与费用模型、止损止盈、参数扫描、交易明细、回测记录。
- 研究：数据质控 → 因子检验 → 组合优化 → 稳健回测 → 执行成本，内置示例面板可先把流程跑通，再切到自己的真实日线。
- 数据：按代码 / 名称获取东方财富前复权日线（A 股 / ETF / 美股），或导入 CSV；可导出。
- 实时：腾讯公开行情 2 秒快照；预测：1 分钟线 + 蒙特卡洛给出多周期上涨概率。
- 全部本地运行：localStorage 持久化，可导出 / 导入备份。

### 研究模块口径

| 步骤 | 做什么 | 关键指标 |
| --- | --- | --- |
| 1 数据质控 | 对数收益、Winsorize、偏度 / 峰度 / 异常值、跳空检查、频率转换 | 年化波动、日胜率、样本区间 |
| 2 因子检验 | 动量 / 短期反转 / 低波动 / EP / BP / 小市值，行业 + 市值中性化 | IC、IR、t 值、胜率、多空价差、累计 IC |
| 3 组合优化 | 均值方差、风险平价、Black-Litterman 主观观点 | 有效前沿、夏普、HHI、风险贡献 |
| 4 稳健回测 | 训练窗选参、测试窗评估的滚动检验 | 样本外年化、胜率、过拟合折损 |
| 5 执行成本 | Almgren 平方根冲击 + 价差 + 佣金，TWAP / 分片 | 冲击 bp、完成天数、占 ADV、成交率 |

`X_EP = EPS / P_t`，`X_BP = BPS / P_t`，标准化 `z = (x − μ) / σ`，
`IC_t = Corr(X_t, R_{t+1})`（Spearman 秩相关），`IR = IC 均值 / σ(IC)`，`|t| > 2` 视为显著。
真实日线缺少 EPS / BPS 时，估值类因子标成「缺少数据」并自动从合成权重里剔除。
